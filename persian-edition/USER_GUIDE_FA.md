# راهنمای اجرای محلی نسخهٔ فارسی

۱. شاخهٔ `persian-translation` مخزن خود را دریافت یا به‌روز کنید و کل مخزن را در `C:\single-cell-best-practices` نگه دارید؛ فایل‌های BAT را به‌تنهایی جابه‌جا نکنید.

۲. Python نسخهٔ ۳٫۱۱ یا بالاتر، Node.js نسخهٔ LTS همراه npm، و Git for Windows را نصب کنید و گزینهٔ افزودن آن‌ها به PATH را فعال کنید.

۳. وارد پوشهٔ `C:\single-cell-best-practices\persian-edition` شوید. ابتدا `SETUP_PERSIAN_BOOK.bat` و سپس `BUILD_PERSIAN_BOOK.bat` را دوبار کلیک کنید. این دو مرحله به اینترنت نیاز دارند. پایان موفق هر مرحله باید با کد خروج صفر همراه باشد.

۴. برای خواندن، `START_PERSIAN_BOOK.bat` را دوبار کلیک کنید. سرور تنها روی رایانهٔ خودتان اجرا می‌شود و مرورگر با نشانی نمایش‌داده‌شده باز خواهد شد. پنجرهٔ فرمان را باز نگه دارید.

۵. برای توقف، در همان پنجره Ctrl+C بزنید. اگر ویندوز دربارهٔ پایان کار batch پرسید، آن را تأیید کنید.

۶. پس از به‌روزرسانی ترجمه‌ها، سرور را متوقف کنید، مخزن را به‌روز کنید و دوباره BUILD و START را اجرا کنید.

۷. اگر خطایی رخ داد، پیام پنجره و پوشهٔ `logs` را بررسی کنید. `DIAGNOSE_PERSIAN_BOOK.bat` اطلاعات تشخیصی جمع می‌کند. بسته‌شدن پنجره به معنی موفقیت نیست؛ باید گزارش را بررسی کرد.

این راه‌اندازها هنوز روی ویندوز واقعی آزمایش نشده‌اند. بسته‌بندی همهٔ منابع برای مطالعهٔ کاملاً آفلاین نیز هنوز تأیید نشده است. ترجمهٔ کتاب ناقص است و فقط بخش‌های دارای پیش‌نویس فارسی نمایش داده می‌شوند. این راهنما به معنی پایان ترجمه یا موفقیت ممیزی نهایی نیست.
